# прокачка — telegram mini app

личный рпг-трекер навыков: уровни, ранги, квесты (свои и командные), награды и вишлист, путь роста.
бесплатный стек, всё самодельное. актуально на 22.10.2026.

## где что живёт

| что | где |
|---|---|
| приложение | https://prokachka.pages.dev (cloudflare pages, проект `prokachka`, прямая загрузка `index.html` + `welcome.jpg`) |
| бот | @prokachkaaa_bot, cloudflare worker `prokachka-bot` |
| данные | база cloudflare d1 `prokachka-data` (привязка `DB`), кэш в браузере (localStorage) |
| прочее у бота | kv `USERS`, секрет `BOT_TOKEN`, расписание (cron) для напоминаний о дедлайнах |
| код | github `karoleenok/prokachka`: `index.html` (всё приложение одним файлом), `worker/worker.js` (бот) |
| копии на маке | `~/github/prokachka-tg` |

## что умеет (v69)

- **уровень и ранги**: опыт за записи, 10 xp = 1 монета, ранги в мужском роде, сезон месяца, фокус сезона ×1.5
- **навыки**: портрет героя (радар), звания навыков, автонавык
- **квесты**: свои и командные; этапы и дедлайны, ответственные с аватарками, комментарии, уведомления в боте обо всём, экспорт в календарь (.ics), личный квест можно сделать командным
- **ответственные**: в задаче командного квеста их может быть несколько; в команде есть клод (помощник со значком, уведомления ему не уходят)
- **уведомления в боте**: приходят тем, кто связан с задачей (ответственные, автор, участники обсуждения), карточкой «квест / суть / кто поставил / дедлайн / ответственные»; если новых задач больше трёх, прошлые уведомления удаляются и остаётся одно сводное со списком и кнопкой
- **выполненные задачи** остаются на своём месте, просто зачёркиваются
- **таймлайн (гант)**: в карточке квеста переключатель «список | таймлайн»; в «пути» вкладка «квесты» со всеми квестами на одной шкале: этапы ромбиками, линия «сегодня», длительность, ответственный, выходные затенены
- **путь**: лента с календарём месяца, график, «до и после» («бой с тенью 🧿 / или игра с самим собой»)
- **награды**: копилка «на что копим», вишлист
- **синхронизация** телефон ↔ компьютер через сервер бота, проверка в чате, архив удалённого с восстановлением
- **чистый интерфейс**: пояснения под «?», функции открываются постепенно (после 5 записей)
- **новости и обновления**: колокольчик в шапке со счётчиком непрочитанного, у обновлений кнопки «посмотреть» и «протестировать». новость добавляется в массив `NEWS` в `index.html` или в файл `news.json` рядом с ним (тогда приложение перевыпускать не нужно). в новости пишем только новые функции, не правки внешнего вида

## как обновлять

1. правка `index.html` → загрузить на cloudflare pages (deployments → new, production)
1a. код бота можно выложить прямо из браузера на dash.cloudflare.com: fetch PUT `/api/v4/accounts/<acc>/workers/scripts/prokachka-bot/content` (multipart: metadata `{"main_module":"worker.js"}` + файл). привязки (BOT_TOKEN, DB, USERS) при этом сохраняются. проверка версии: адрес бота `/v`
2. правка бота → открыть редактор воркера `prokachka-bot`, вставить `worker/worker.js`, deploy
3. откат: взять нужный `index-vNN.html` из `архив-версий` на маке и загрузить как `index.html`

## v90 (31.10.2026)
- дедлайн квеста можно поменять. свой квест: кнопка «перенести» (или «изменить» у дедлайна в «в чём суть») открывает выбор: следующий период, завтра, через неделю, конец месяца или любая дата. своя дата хранится с пометкой `dueSet`, полоска времени тогда считается от создания квеста до дедлайна.
- командный квест: нажатие на «дедлайн квеста» и на дедлайн этапа открывает тот же выбор: поменять, поставить или убрать. дедлайн задачи меняется в самой задаче. бот не менялся.
